# 公開・プライバシー確認

[READMEに戻る](../README.md)

## 今回の点検結果

- 管理対象の作業ファイル・ステージ済み内容・到達可能なGit履歴に、実機のIP・ホスト名、個人ホームの絶対パス、私用メール、認証トークン・秘密鍵の既知パターンは検出されていません。
- `.env` と `firmware/paperdiy/secrets.h` は管理対象外です。両サンプルの代入値は空欄で、コメントにはプレースホルダー・既定値・公開NTPサービスの例だけを記載しています。
- Gitのauthor/committerメールはGitHubのnoreply形式です。GitHub表示名・アカウントに結び付くnoreply IDは履歴に残ります。
- fixtureにはメトリクス・時刻・プラン・モデル名・ハードウェア型番が含まれます。直接の連絡先や接続先はありません。
- 公開サンプル画像 `docs/images/sample.png` はfixtureだけから生成した画像です。この1ファイルだけをバイナリの許可対象とし、その他の画像・バイナリは要レビューとして検出します。

## 再実行

```sh
.venv/bin/python scripts/check_public.py --history
.venv/bin/python scripts/check_public.py --history --json
```

Git管理対象の現在のテキストとステージ済み内容、全refから辿れるコミットの各ファイル、コミットメッセージ、作者・コミッターのメールを調べます。個人のローカルアカウント名も文字列検索します。追加で点検したい名前・識別子があれば、`--sensitive-term` を手元のコマンドで指定できます。値をIssueやコミットには貼らないでください。

検出結果には場所と分類だけを表示し、一致した秘密の値は表示しません。環境ファイル・秘密ヘッダーを追跡していた場合は、内容を開かずファイル名だけで検出します。Git管理外のログ・DB・生成物は読みません。

## 点検するもの

- loopback・bind用wildcard以外の固定IPv4/IPv6、個人ホームの固定パス。
- 私用メール、ローカルネットワーク名、未確認の固定URLホスト。
- よく使われる認証トークン、秘密鍵のヘッダー、値入り設定サンプル。
- 環境ファイル・秘密ヘッダー・DB・ログ・ファームウェアバイナリの追跡。
- 履歴中の同種の内容、GitHub noreply以外の作者メール。

参照用に同梱するGitHub・M5Stack・Espressifの公式URLは許可しています。設定サンプルのコメントも秘密・個人情報の検査対象にしますが、空欄の代入行とプレースホルダー例は値入り設定と判定しません。公開サンプル画像以外のバイナリはレビュー対象です。

## 点検の限界と運用

これは既知パターンの静的点検です。任意の人名・住所・SSID・独自トークン、画像内の文字を完全には識別できません。ローカルで不要になったGitオブジェクト、別リポジトリ、未pushの外部サービスの状態は対象外です。

診断ログには取得先URLやレスポンス先頭200文字が含まれ得ます。DB・paper.json・PNGにも実際の利用状況が含まれるため、共有時は内容を確認してください。公開用スクリーンショットはfixtureから生成すると再現しやすくなります。

GitHub上ではpush/PRのCIで同じテスト・点検を行います。現在のCIは認証情報や実機接続を使いません。スキャンが通っても、公開前にステージした差分と添付画像を目視してください。
